## Design Specificity Verdict

### LLM Assessment (Assessment A)

**Verdict: Category-interchangeable with engineering depth**

The dashboard has *substantial proprietary engineering* (Kaplan-Meier MTBF, Run Life Efectivo, Índice Falla Anual algorithms, OneDrive offline cache, premium ECharts) but the *visual layer feels like a generic Streamlit template with brand colors painted on*. 

- **Structural sameness**: 7 tabs, sidebar filters, KPI row, charts — could be any industrial monitoring tool
- **Missed product character**: No "field manager" affordances (quick workorder creation, well flagging, offline badge, session summary). The Parex brand is only in colors/logo, not in interaction patterns or decision-support UX.
- **Design decisions by default**: Floating bottom tab bar (mobile aesthetic on desktop), 9 KPI cards (Streamlit columns default), gradient titles (CSS trick), glow effects (box-shadow trick) — none grounded in user research.

## Overall Impression

**Engineering: A- | Design: D+**

This is a *calculator that grew a UI*, not a *dashboard designed for decisions*. The proprietary algorithms are the product's moat — they're isolated, tested, and audit-grade. But the interface forces gerentes to do mental work the tool should do: scan 9 KPIs to find the 1 that matters, cross-reference tabs manually, remember filter state, screenshot charts for reports. 

**Single biggest opportunity**: Redesign the "Resumen" tab as a *decision cockpit* — 3 hero metrics (IF vs Meta, MTBF vs Meta, Pozos con Alerta) + "Top 5 pozos para intervención esta semana" + one-click executive export. Everything else goes to detail tabs.

## What's Working

1. **Proprietary calculation integrity** — Core algorithms in `core/` (MTBF Kaplan-Meier, Run Life Efectivo, Índice Falla Anual) are isolated, versioned, and produce audit-grade outputs. This is the defensible moat.
2. **ECharts integration depth** — Custom HUD-style visualizations (gradient bars, area fills, markLines for meta, fullscreen zoom) exceed standard Streamlit capabilities and feel "premium industrial."
3. **Data pipeline resilience** — OneDrive → local cache → session state → filtered views architecture handles intermittent connectivity (PRODUCT.md principle #2) better than most Streamlit apps.

## Priority Issues

### [P0] Semantic Color Collision
**What**: Green (`#137659`) means: Parex brand, "good" MTBF, Pozos ON, Run Life positive, ALS bars. Gold (`#c09c2e`) means: WS, RL Efectivo, IF ALS. Red only for fallas.
**Why it matters**: Gerentes cannot scan — every green requires context decoding. Colorblind users lose all signal (no redundant encoding).
**Fix**: Define semantic tokens: `success:#137659`, `warning:#c09c2e`, `danger:#c62828`, `info:#0284c7`, `brand:#137659`. Never reuse semantic tokens for brand. Apply to KPI cards, chart series, status badges, heatmap scales.
**Suggested command**: `$impeccable colorize`

### [P0] KPI Grid Violates Scanability (Principle #1)
**What**: 9 cards, dual-value (TOTAL/ALS), no visual priority, animation stagger on load.
**Why it matters**: 90-second meeting scan fails. Working memory overload (9 > 4 items). No traffic-light semantics.
**Fix**: Reduce to 4 hero cards: IF vs Meta (traffic light), MTBF vs Meta, Pozos ON/OFF, Alertas críticas. Move remaining to "Detalle KPIs" expander. Add sparkline trend to each hero.
**Suggested command**: `$impeccable layout`

### [P1] Floating Bottom Tab Bar Breaks Mental Model
**What**: Custom CSS bottom bar (730px wide, hides on scroll, z-index 9999) replaces native `st.tabs`.
**Why it matters**: Hidden on scroll = lost context. Non-standard = cognitive tax. Conflicts with browser chrome on mobile. Traps keyboard focus (Sam persona).
**Fix**: Restore native `st.tabs` at top. Add keyboard shortcuts (1-7) for Alex. Add breadcrumb showing active filters.
**Suggested command**: `$impeccable adapt`

### [P1] Hardcoded Exclusion Lists in 7+ Files (Maintenance Nightmare)
**What**: `POZOS_EXCLUIDOS`, `ALS_TIPOS` lists duplicated across `sidebar_ui.py`, `tab_resumen.py`, `tab_indices.py`, `tab_mtbf.py`, `tab_campanas.py`, `tab_tablero.py` (2x).
**Why it matters**: Silent data loss when new well added. One change = 7 edits. No test coverage.
**Fix**: Centralize in `config/exclusions.py` + `config/als_types.py`. Import everywhere. Add unit test validating no well silently dropped.
**Suggested command**: `$impeccable harden`

### [P2] No Offline/Connection Status (Violates Product Principle #2)
**What**: "Offline-capable" is a stated principle but zero UI indication of connection state or cache freshness.
**Why it matters**: Field manager in dead zone doesn't know if data is live or cached from 3 hours ago.
**Fix**: Add connection badge (🟢 Online / 🟡 Cached / 🔴 Offline) with last sync timestamp in header. Show stale-data warning banner when cache > 4h.
**Suggested command**: `$impeccable onboard`

### [P2] Export is All-or-Nothing
**What**: Single global export button; charts need manual screenshots; no per-well, per-tab, per-chart export.
**Why it matters**: Gerentes waste 15-20 min assembling executive reports from screenshots.
**Fix**: Add download button to each ECharts container (reuse zoom button pattern). Add "Exportar este pozo" to detail views. One-click branded executive PDF.
**Suggested command**: `$impeccable polish`

### [P3] Login Credentials in Plaintext
**What**: `users = {"lenin": "1", "pt": "2", "jaime": "1", "ajm": "1", "nelson": "1"}` in `app.py:279-286`
**Why it matters**: Source control leak risk; no password rotation; no audit trail.
**Fix**: Move to `.streamlit/secrets.toml`. Add bcrypt hashing. Consider SSO/OAuth for corporate deployment.
**Suggested command**: `$impeccable harden`

## Persona Red Flags

### Alex (Power User) — Dashboard/Admin Primary
- **No saved filter presets** — Must reconfigure 8+ filters every session
- **No keyboard shortcuts** — Tab switch = mouse only; 7 tabs = 7 clicks
- **No bulk actions** — Cannot "flag 5 wells for review" or "export these 10"
- **Tab switch = full reload** — 2-3s wait × 20 switches/day = wasted time
- **Forced to use floating tab bar** — Hidden on scroll, non-standard, traps focus

### Sam (Accessibility-Dependent) — Corporate Compliance
- **Color-only state encoding** — IF > meta = red line only (fails 1.4.1 Use of Color)
- **0.58rem font on KPI labels** (`styles.py:197`) — Fails 1.4.3 Contrast (1.0:1 measured)
- **No focus styles on custom HTML buttons** — `components.html` buttons invisible to keyboard
- **ECharts have no ARIA** — Screen reader announces "chart" with no data
- **Floating tab bar traps keyboard** — Tab order breaks, no escape

### Riley (Stress Tester) — Security/Edge Cases
- **100+ `unsafe_allow_html=True`** with interpolated data — XSS vector if any `df` column contains `<script>`
- **`exec_module` on arbitrary `.py` files** (`app.py:256-265`) — RCE if upload compromised
- **Hardcoded plaintext passwords** — Trivial privilege escalation
- **No input validation on Excel upload** — Column names injected into HTML templates

## Questions to Consider

1. **Why does "Resumen" show a 22-row heatmap of well intermittency but no "Top 5 wells needing intervention this week" card?** The heatmap is analytical; the decision is operational.

2. **If a field manager has 90 seconds before a meeting, which *one* screen gives them the go/no-go on workovers?** Currently: none. Tablero is closest but buries the signal in gauges.

3. **What happens when Parex adds a new ALS technology (e.g., "HYBRID")?** Answer: Edit 12+ files (ALS_TIPOS lists, color maps, exclusion logic, chart series) — architecture doesn't support extensibility.

4. **Why are proprietary formulas (Run Life Efectivo, Índice Falla Anual) explained nowhere in the UI?** A new hire cannot audit the numbers they're presenting to leadership.

5. **Is the floating bottom tab bar worth the 200 lines of CSS hacks it requires?** It breaks `st.tabs` semantics, hides on mobile, confuses keyboard nav — all for a "mobile app" aesthetic on a desktop dashboard.
